# Shell-first complete drive article — REVIEW ONLY

These are exports from the single `../../Roller-300.nbcad` master. They are not separate working CAD models. No print or powered test is released.

The first complete article uses the full housing and curved hatch, one input carriage, one inner and one outer wheel-bearing cap, one inner and one outer input-bearing cap, and one rigid wheel. Purchased bearings, shafts, belt, hub, metal spacers, servo/horn, clutch and fasteners complete the intended drive. Several of those interfaces remain HOLD in the canonical plan/BOM.

Bed-oriented review candidates:
- `main-shell-axle-vertical.stl` OR `main-shell-opening-down.stl` — compare, do not print both by default.
- `curved-hatch-axle-vertical.stl` — one.
- `left-input-carriage-floor-down.stl` — one; axle-vertical is retained as an orientation comparison only.
- `wheel-cap-inner-axle-vertical.stl` and `wheel-cap-outer-axle-vertical.stl` — one each.
- `input-cap-inner-axle-vertical.stl` and `input-cap-outer-axle-vertical.stl` — one each.
- `left-wheel-axle-vertical.stl` — one. This rigid rim is230 mm OD;246 mm includes the deferred tread allowance.

Files ending `assembly-coordinates.stl` retain the native CAD location for verification, not slicer placement. Other files apply rigid rotations/translations only. No geometry is generated outside NoBS CAD. The exported source/body IDs, hashes and topology results are recorded under `../../checks/`.

The named STL candidates all pass an offline X2D0.4 slice with generic PETG,0.2 mm layers,5 walls,15% gyroid and3 mm brim. The main shell consumes approximately1.19 kg axle-vertical or1.10 kg opening-down INCLUDING support waste, about30 hours either way. Estimated shell plastic excluding supports is597 g or623 g respectively. The hatch is about145 g excluding supports. These are profile estimates, not actual weighed parts.

Native slicer preview PNGs are generated by Bambu Studio. They are not screenshots of the CAD desktop or proof of support removability. The unrelated Windows security prompt prevented final CAD screenshots and visual toolpath inspection. No orientation has been released.

Before printing: close the current fit/retention/tool-access gates, print representative bearing/nut/strap coupons, inspect supports and their removal paths, and confirm the real material/nozzle. Before power: complete horn, clutch and shaft-retention interfaces and establish bounded torque/current/temperature/slip limits and cutoff behavior.

The older `../drive-end-section/` files are unchanged historical fit candidates, not this article. See the canonical plan and BOM for the current design; do not mix old carrier/spine parts with this shell.
