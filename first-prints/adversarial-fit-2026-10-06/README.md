# S20 one-drive unpowered fit prints

This folder predates the S21 chassis access corrections. Its wheel STL and individual wheel estimate are historical: the four hub screw drivers were blocked by the outer wheel plate, and support extraction from the broad closed wheel cavities remains unqualified. Do not print this wheel. A current native wheel export, slice and support-removal review are required after the access corrections.

The ten smaller drivetrain STLs are separate from that wheel correction. The individual estimate projects and original ten-part review plate are superseded as print instructions: actual toolpaths/settings checks found support cleanup and GUI-preset issues. Start with [the corrected five-part fit gate](../receiving-fit-gate-2026-10-06/Roller-300-small-fit-gate.3mf). Then use the corrected carrier trial before larger parts. See [the fresh print decision](../../design/print-decision-2026-10-06/README.md).

Current native exports for PETG /0.4mm X2D:11 connected pieces,0.2mm layers,5 walls,15% gyroid. `source.json` records native-body and archive hashes; `slice-checks.json` records warning-free individual Bambu slices. Placement applies rigid rotation/translation only.

The original ten-part Bambu project is historical and should not be printed. The approximately609g /15.74h wheel figure is a historical estimate of the superseded geometry; it is not a current wheel print instruction.

Parts: roof-open fit section, sliding carrier,48T output pulley, upper servo bridge, positive REX horn adapter,24T keyed pulley, mouth retainer, two input retainers, center retainer and wheel. Do not use old clamp/collar print files or the inspection cutaway. No physical print or test has occurred.

See [PLAN.md](../../PLAN.md) for ordered assembly and [BOM.xlsx](../../BOM.xlsx) for hardware. Physical fits/endplay and powered/full-barrel qualification remain pending.
